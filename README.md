### Introduction
This repository contains all the notebooks used for the Artificial Neural Network and Deep Learning challenge. The challenge consisted in classifying possible tumor flesh types, using images made by ogres 🧌 in a ship. Some of the images were contaminated with memes or green blobs. The challenge was held in Kaggle with a final scoreboard. Please note that this challenge was very difficult, in particular the scores were overall low (the best one was around 42%) and very close to each other.
